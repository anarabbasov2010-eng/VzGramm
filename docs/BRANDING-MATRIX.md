# VzGramm branding matrix

All Android launcher variants must resolve to the same visual source:

- adaptive launcher
- round launcher
- legacy launcher fallback
- debug launcher
- release launcher
- store icon
- notification icon where applicable

Rules:
1. Product name is always **VzGramm** in user-facing UI.
2. Package identity is centralized; do not hard-code alternate product names.
3. Do not introduce a second icon design.
4. Dark/OLED surfaces use the same mark and geometry.
5. Custom feature work stays out of this phase.
