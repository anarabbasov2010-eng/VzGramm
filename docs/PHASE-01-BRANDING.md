# Phase 01 — VzGramm branding

This phase establishes the application identity before custom functionality is introduced.

## Included

- VzGramm application name.
- Consistent launcher identity.
- Adaptive Android launcher icon.
- Dark/OLED-safe icon palette.
- Shared vector geometry.
- Branding documentation.

## Deliberately excluded

- ExteraGram features.
- AyuGram features.
- Additional plugins.
- Custom Telegram UI changes.
- Network/backend changes.

Those belong to later implementation phases.
