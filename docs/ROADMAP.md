# VzGramm roadmap

1. Branding and repository foundation.
2. Import/align the upstream Telegram Android client source.
3. Replace application identity and launcher assets throughout the build.
4. Establish a clean VzGramm build pipeline.
5. Add ExteraGram-compatible functionality in isolated modules.
6. Add AyuGram-inspired functionality where licensing and implementation permit.
7. QA, crash checks, localization and release packaging.

The current repository state intentionally stops at step 1.
