# VzGramm build foundation

This phase creates a small, independently buildable Android shell so branding and package identity can be validated before importing the much larger upstream Telegram client.

The production client source is the next integration step. It must retain the upstream GPL-2.0 notices and then be changed systematically to the VzGramm application identity.

Custom ExteraGram/AyuGram features are deliberately not present in this phase.
