# VzGramm Branding

## Master mark

The VzGramm mark is a minimal geometric **V** inside a soft-square launcher tile.

Design rules:
- dark neutral base
- white/light mark
- restrained contrast
- no neon
- no unrelated alternate logos
- identical proportions across every size

## Required application name

Use **VzGramm** in user-facing application branding.

## Asset rule

All generated launcher variants must be rasterizations of the same master geometry. Do not redraw the logo separately for individual densities.
